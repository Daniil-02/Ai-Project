## Зв'язки

| Таблиця А | Таблиця Б | Тип зв'язку (1:N / M:N / 1:1) | Як зроблено (поле чи таблиця зв'язку) | Чому саме такий (одне речення) |
| :--- | :--- | :--- | :--- | :--- |
| `events` | `profiles` | M:N | Таблиця `event_registrations` (`event_id`, `profile_id`) | Один учасник гільдії може записуватися на багато ігрових подій, і в одній події бере участь багато гравців. |
| `events` | `event_comments` | 1:N | Поле `event_id` у таблиці `event_comments` | Одна ігрова подія містить багато коментарів обговорення, але кожен коментар належить лише одній конкретній події. |

## Відповідність поле → екран

| Таблиця | Поле | Екран, на якому поле з'являється | Рішення | Причина |
| :--- | :--- | :--- | :--- | :--- |
| `profiles` | `id` | зв'язок | лишити | Первинний ключ для ідентифікації учасника гільдії та зв'язку M:N. |
| `profiles` | `nickname` | Склад гільдії; Сторінка події | лишити | Відображається у таблиці складу гільдії та у списках учасників рейду. |
| `profiles` | `character_class` | Склад гільдії | лишити | Показується у колонці «Клас» на сторінці `/members`. |
| `profiles` | `role` | Склад гільдії | лишити | Використовується для відображення та фільтрації за бойовою роллю на `/members`. |
| `profiles` | `rank` | Склад гільдії; Сторінка події | лишити | Показує ранг гравця («Офіцер» або «Учасник») у таблиці складу й деталях події. |
| `profiles` | `active_status` | Склад гільдії | лишити | Відображає поточний статус активності гравця на сторінці `/members`. |
| `profiles` | `avatar_url` | жоден | видалити | Жоден екран MVP не виводить графічні аватари користувачів. |
| `profiles` | `created_at` | жоден | видалити | Час реєстрації учасника не показується на жодному екрані. |
| `events` | `id` | зв'язок | лишити | Первинний ключ події для маршруту `/events/[id]` та зв'язків із заявками й коментарями. |
| `events` | `title` | Головна; Розклад подій; Нова подія; Сторінка події | лишити | Назва рейду вводиться у формі та показується на всіх екранах подій. |
| `events` | `date_time` | Головна; Розклад подій; Нова подія; Сторінка події | лишити | Дата й час початку рейду вводяться при створенні та виводяться у картках. |
| `events` | `description` | Нова подія; Сторінка події | лишити | Опис цілі рейду заповнюється у формі `/events/new` і показується на `/events/[id]`. |
| `events` | `max_slots` | Головна; Розклад подій; Нова подія; Сторінка події | лишити | Ліміт місць основного складу потрібен для відображення заповненості загону. |
| `events` | `status` | Головна; Розклад подій; Сторінка події | лишити | Статус («Набір відкрито» / «Завершено») потрібен для фільтрації та блокування набору. |
| `events` | `tier` | Розклад подій; Сторінка події | додати | Надзаголовок складності рейду («Рейд · Міфічний») є на екранах `/events` та `/events/[id]`, але модель його пропустила. |
| `events` | `created_at` | жоден | видалити | Жоден екран не показує технічну дату створення запису події. |
| `events` | `updated_at` | жоден | видалити | Час останнього редагування події не відображається в інтерфейсі. |
| `events` | `ai_tactics_plan` | жоден | видалити | Поле потрібне лише відкладеній функції генерації тактики через ШІ (ПР 6). |
| `event_registrations` | `event_id` | зв'язок | лишити | Зовнішній ключ на таблицю `events` для реалізації зв'язку «багато до багатьох». |
| `event_registrations` | `profile_id` | зв'язок | лишити | Зовнішній ключ на таблицю `profiles` для реалізації зв'язку «багато до багатьох». |
| `event_registrations` | `combat_role` | Сторінка події | лишити | Бойова роль гравця у конкретному рейді, яку обирає учасник під час запису. |
| `event_registrations` | `slot_status` | Головна; Розклад подій; Сторінка події | лишити | Визначає розподіл між «Основним складом» і «Резервом» та підрахунок зайнятих слотів. |
| `event_registrations` | `registered_at` | жоден | видалити | Точний час подання заявки не виводиться у списках основи чи резерву. |

| `event_comments` | `comment_time` | Сторінка події | лишити | Час публікації повідомлення, що відображається у шапці кожного коментаря. |
| `event_comments` | `content` | Сторінка події | лишити | Текст коментаря або замінений напис після приховування модератором. |
| `event_comments` | `reports_count` | Сторінка події | лишити | Лічильник скарг, який виводиться у позначці «На розгляді модератора». |
| `event_comments` | `is_hidden` | Сторінка події | лишити | Ознака прихованого коментаря для зміни стилю відображення та приховування кнопок дій. |

### Видалені поля

| Таблиця | Поле | Чому, на мою думку, модель його додала |
| :--- | :--- | :--- |
| `profiles` | `avatar_url` | Модель додала поле аватара за шаблоном типових ігрових профілів, хоча в таблиці `/members` його немає. |
| `profiles` | `created_at` | Модель автоматично додає системні часові позначки в кожну таблицю за звичкою. |
| `events` | `created_at` | Стандартне службове поле аудиту, яке не виводиться на жодному екрані застосунку. |
| `events` | `updated_at` | Додано моделлю «на майбутнє» для відстеження змін, хоча інтерфейс його не використовує. |
| `events` | `ai_tactics_plan` | Модель взяла це поле з опису відкладеної ШІ-функції, яка не входить до першої версії MVP. |
| `event_registrations` | `registered_at` | Модель припустила сортування заявок за часом у таблиці, але екран `/events/[id]` не показує час подання заявки. |
